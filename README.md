# Upwork Market Analysis

## Project Overview

This project analyzes the Upwork marketplace to identify the most in-demand data analytics skills, technologies, and project characteristics.

The goal is to understand current market demand and provide insights for aspiring data analysts.

---

## Research Questions

1. What skills are requested most frequently?
2. Which programming languages appear most often?
3. What tools are employers looking for?
4. What experience level is most commonly required?
5. What budgets and hourly rates are most common?
