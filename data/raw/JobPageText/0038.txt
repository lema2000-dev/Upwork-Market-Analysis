Job Posting: Real-Time Audio-Reactive Prototype Developer (v0.0 Proof of Concept)

Title
Real-Time Audio-Reactive Light/Visual Prototype (1-2 Week Build)

Summary
I'm building an early proof of concept for an AI-assisted live performance system. I need a small, working demo that proves a simple concept: live audio input → real-time signal analysis → a visible light or on-screen reaction, with low latency. This is a scoped, standalone prototype — not part of a larger existing codebase.

What You'll Build
- Capture live audio from a standard USB microphone
- Detect in real time: (1) volume/RMS level changes, (2) tempo/BPM changes
- When a signal crosses a threshold, fire an event that triggers a visible reaction — either a smart light (e.g. Govee, Philips Hue) changing color/brightness, or an on-screen visual changing on a connected display
- Log every signal reading and triggered event with timestamps, so latency can be measured afterward
- A basic start/stop control (keypress or button — no voice activation needed for this phase)

Explicitly Out of Scope
No camera/video, no AI/LLM reasoning layer, no dashboard UI beyond start/stop, no wireless audio feedback, no custom hardware enclosure, no cloud/multi-user components. Everything runs locally on one machine.

Deliverable
A working local demo (laptop or mini PC) showing the full loop live, plus a logged latency measurement from signal detected to reaction fired.

Success Criteria
- Reaction latency under ~1 second, documented in the log
- Runs reliably for a 10-15 minute continuous test without crashing
- Latency log file provided so timing can be independently verified

Tech Stack
Open to your recommendation — Python or JavaScript/Node both fine. Comfortable with real-time audio libraries (e.g. PyAudio/librosa/aubio, or Web Audio API) a plus.

What to Include in Your Proposal
1. Relevant experience with real-time audio-reactive systems (examples/portfolio welcome)
2. Your estimated latency for this scope, and why
3. Fixed-price quote and timeline (please also quote separately for an optional "voice-activated start/stop" add-on)
4. Whether you'd want a short call first to clarify scope

Timeline
Target start within the next 1-2 weeks; build itself estimated at 1-2 weeks of work.
